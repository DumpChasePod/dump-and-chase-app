# Dump & Chase Podcast App — Version 5

Version 5 turns the Phantoms section into a Game Center.

New:
- Full published 2026–27 Youngstown Phantoms regular-season schedule
- Game Center dashboard
- Schedule browser
- Official roster link
- Official standings link
- Next-game hero
- Persistent in-app audio player
- Buzzsprout episode feed support
- Dump & Chase logo/branding

The schedule is based on the official Youngstown Phantoms 2026–27 schedule published on the team's athletics site.
